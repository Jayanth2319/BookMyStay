
## Use Case 1: Application Entry & Welcome Message
- **Goal:** Establish a clear and predictable starting point for the application.  
- **Flow:**  
  1. User runs the application.  
  2. JVM invokes the `main()` method.  
  3. Application prints a welcome message with name and version.  
  4. Application terminates.  

### Expected Output
```text
Welcome to Book My Stay App!
Hotel Booking System v1.0
